# Campus Closet QA Checklist

## Login
- Verify student login works.
- Verify admin login works.
- Verify invalid login shows an error message.

## Registration
- Verify new users can register with a Southern email.
- Verify password fields work correctly.

## Browse Listings
- Verify listings appear on the browse page.
- Verify listing details open correctly.

## Create Listing
- Verify a student can create a listing.
- Verify required fields are validated.

## Profile
- Verify profile information loads correctly.
- Verify user listings appear on the profile page.

## Admin Dashboard
- Verify pending reports display correctly.
- Verify total users display correctly.
- Verify total listings display correctly.

## Logout
- Verify users can successfully log out.
